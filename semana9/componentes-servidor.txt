Sistema operativo: Es el software base que administra el hardware del servidor (como la memoria y el procesador) y permite que otros programas se ejecuten de forma segura. Actúa como el intermediario invisible entre los componentes físicos y el resto de las aplicaciones.
Node.js: Es un entorno de ejecución que permite utilizar el lenguaje JavaScript fuera del navegador, directamente en el servidor. Se usa principalmente para construir la lógica de fondo de la plataforma y permitir que esta sea rápida y capaz de manejar muchas conexiones simultáneas.
Aplicación server.js: Es el archivo de código principal que define la lógica y las reglas de tu plataforma web. Su función es arrancar el servidor a través de Node.js, recibir las peticiones de los usuarios (como cargar una página o guardar un voto) y decidir qué responder a cada una.
Puerto: Es un canal de comunicación virtual e identificado por un número dentro del servidor que dirige el tráfico de red hacia una aplicación específica. Permite que el servidor sepa exactamente a qué programa (como a tu archivo server.js) debe entregarle los datos que llegan desde internet.
Logs: Son archivos de texto que registran de forma cronológica todo lo que sucede en el servidor, incluyendo accesos de usuarios y errores del sistema. Funcionan como una bitácora o "caja negra", permitiendo a los administradores diagnosticar fallas y auditar la seguridad de la plataforma.
